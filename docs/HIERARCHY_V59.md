# v0.59 Home Hierarchy — Games, Stats & News First

The Home screen is now ordered around what is most immediately engaging to a player.

1. **Do This Now** — blocking GM decisions, Game Day/Advance action.
2. **Urgent team context** — medical or club alerts that materially affect the next game.
3. **Game context** — today's game when scheduled, otherwise the compact Next Game card.
4. **Stats + news** — Since Your Last Advance digest, SportsCenter performance coverage, League Wire, NBA Today headlines.
5. **Supporting league presentation** — broader editorial/event/studio/social modules.
6. **Franchise Deep Dive** — staff, career, development, G League, draft-watch and other specialist systems.

## Daily training retirement

The v0.32 daily activity model is retired from the player-facing loop in v0.59. Old save data is preserved for compatibility, but the current-day activity is cleared on access and no new plan can be selected. Training Camp remains a separate offseason phase and is not affected.

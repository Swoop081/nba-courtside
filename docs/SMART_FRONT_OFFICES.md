# Smart Front Offices — v0.11

## Team direction
Every team is continuously classified using current record, top-eight roster strength, core age and young talent:
- CONTENDER
- PLAYOFF PUSH
- RETOOL
- REBUILD

This is recalculated as the universe changes. A rebuilding club can become a contender; a veteran contender can slide into a retool.

## GM archetypes
Each franchise has a deterministic front-office temperament. These are simulation identities, not claims about real executives:
- Star Hunter
- Value Hunter
- Patient Builder
- Aggressive
- Conservative

The archetype modifies how much the CPU protects first-round picks, pays star premiums, values salary efficiency and accepts risk.

## Contextual player valuation
Trade value now includes current OVR, star scarcity, age, development trend, contract cost, positional need, team direction and morale. A 31-year-old high-level starter is more useful to a contender than a rebuild. A rising 21-year-old is worth more to a rebuild.

## Trade block / untouchables
The user's player profile can mark a player SHOPPING or UNTOUCHABLE. CPU teams automatically flag players based on timeline, roster rank, age and trade requests. An untouchable can still be selected in the UI but requires a much larger overpay.

## CPU-to-CPU activity
CPU deals now prefer contender/buyer and rebuild/retool/seller pairings, seek salary-compatible player swaps and add draft compensation when the seller is giving up the better present-day player. Activity rises near the deadline.

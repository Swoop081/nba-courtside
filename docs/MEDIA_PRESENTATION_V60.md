# NBA Courtside v0.60 — Social-Only Media Personalities

## Goal

Reduce broadcast-roleplay clutter on the franchise Home screen while preserving the league-world feeling that media and social reaction provide.

## Rule

Named studio hosts and analyst personalities do not occupy standalone Home modules. Standalone modules are information-first: game context, scores, statistics, performance, transactions and headlines.

Named media personalities may still appear inside the simulated social feed, where the identity itself helps distinguish an insider post, news reaction or league conversation from generic system copy.

## Home result

- Editorial hero: neutral `LEAGUE COVERAGE` identifier.
- SportsCenter: `SCORES + PERFORMANCE`; no host line.
- NBA Today: `HEADLINES · SIMULATED COVERAGE`; no presenter line.
- Inside the NBA / roundtable panel: removed.
- Transaction headline tags: neutral `BREAKING` label.
- Social feed: unchanged and remains the sole intended Home context for media personalities.

This is a presentation-only pass. It does not alter the league simulation or media-event generation underneath the UI.

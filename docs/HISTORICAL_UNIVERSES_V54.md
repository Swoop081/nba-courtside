# v0.54 — Historical Universes + Real Draft Pipeline

## Product rule

**History diverges from the selected start point.** Historical facts establish the starting universe. After the user takes control, trades, standings, playoff outcomes, draft destinations, development, free agency, coaching moves and GM careers are generated by the NBA Courtside simulation.

## Foundation start: 2025–26 Postseason

The first historical package starts **April 13, 2026**, immediately after the retained 2025–26 regular-season game log ends. It seeds:

- all 30 franchises;
- 1,230 completed regular-season results with team scores reconstructed from retained player-game scoring;
- end-of-season player assignments and 2025–26 statistical totals where source evidence resolves cleanly;
- historical-only players generated from source-backed 2025–26 statistical evidence when they are not part of the 2026–27 current-player dataset;
- official 2025–26 salary cap / tax / apron thresholds;
- an explicit data-boundary record inside the save.

### Deliberate foundation limitations

Historical contracts are modeled for playability where exact 2025–26 contract state is not yet packed. The 2026 pick ledger currently starts with modeled own-team origin picks; exact historical traded pick-rights are a later certification layer. These limitations are surfaced in-game and are not represented as exact historical facts.

## Real 2026 draft pipeline

The 2026 class contains the official 60 drafted identities and their official historical pick/team as metadata. The alternate universe does **not** force that destination. Example: AJ Dybantsa carries Washington/No. 1 as historical metadata, but an NBA Courtside save can draft him elsewhere.

Prospect ability remains routed through the existing v0.49 uncertainty/scouting system. The real-world draft order is evidence, not a hidden instruction to recreate the real career.

## Future pipeline

- 2026: official historical 60-player draft identity class.
- 2027: existing source-backed NBA Courtside prospect watch class.
- 2028+: generated future classes until later historical/source-backed packs extend the pipeline.

The architecture is year-keyed so future releases can add opening-night snapshots and historical draft classes without creating a second game engine.

# NBA Courtside — Exhibition Match v0.6

Mobile-first static prototype for GitHub Pages.

## Entry points
- `index.html` — full GM/franchise loop inherited from v0.5, now with an Exhibition Match launcher.
- `exhibition.html` — standalone all-30-team exhibition mode.

## v0.6 headline
Choose any two NBA teams, review proper depth charts and allocated minutes, then watch or fast-sim a complete game with automatic substitutions, fatigue, live lineups, play-by-play, full player minutes and a live/final box score.

Exhibition reads the same frozen current-day player database as the GM shell and will also consume a saved franchise universe from the same browser when one exists.

See `docs/EXHIBITION_MATCH.md` for the engine and validation notes.

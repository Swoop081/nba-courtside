# NBA Courtside — League Pulse v0.8

Current working prototype baseline.

## v0.8 headline
The GM universe now turns persistent Game Day box scores into a visual league-wide feedback loop: live stat leaders, award races, hot teams, player trends, save-generated headline stories and a richer Home dashboard. Exhibition remains only an unlinked development harness.

## Core loop
Build roster → set rotation → play/sim Game Day → accumulate real box scores → League Pulse reacts → make GM decisions → chase the postseason.

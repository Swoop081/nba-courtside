# NBA Courtside v0.64 — Visual Rhythm + Large Imagery System

Built from the v0.63 iPhone Home Screen Icon baseline.

## Purpose
The v0.62 visual pass made many individual rows more readable, but long iPhone screens could still feel like one continuous wall of similarly weighted information. v0.64 establishes a stronger game-wide presentation system: large existing imagery, clear visual chapters, stronger spacing, distinct colour identities, and horizontal rails where dense vertical lists are not the best mobile presentation.

## Locked presentation changes
- Larger player photography throughout roster, depth, contracts, free agency, scouting, live lineups, rotation views and incoming trade offers.
- Larger team marks on next-game, schedule and Game Day surfaces.
- Home is explicitly separated into visual chapters: **Next Up**, **Results + Stats**, **League News**, **Courtside Social**, then the existing Franchise Deep Dive.
- Games use a blue/cyan visual identity; results/statistics use lime; news uses coral/red; social uses violet; required GM actions retain urgent red treatment.
- The league digest is now a spacious 2×2 stat treatment on iPhone instead of four compressed cells.
- SportsCenter performance coverage is photo-led with a much larger featured player image. Secondary results become a horizontal rail rather than a tall stack.
- League Wire becomes a full-width news band with readable multi-line cards.
- NBA Today keeps one large lead headline while secondary headlines become swipeable cards.
- Courtside Social becomes a horizontal card rail so the feed does not add a long wall of posts to Home.
- Team/Deals/More workspace snapshot metrics become swipeable summary cards. Workspace destinations use larger icons, type and touch targets.
- Starting-five cards, roster cards, depth rows, contract rows, free-agent rows, schedule rows and prospect rows receive another size increase for iPhone.
- League tabs remain horizontally scrollable with larger touch targets and more breathing room.
- Game Day and Exhibition receive the same visual rhythm: larger matchup/team marks, larger player faces, photo-led rotation rows, larger live-lineup cards, larger moment cards and more readable coaching controls/box scores.
- Dense underlying simulation/CBA information is not removed. The change is presentation-only and keeps advanced detail underneath the readable summary layer.

## Compatibility
- Save schema remains 25.
- v0.63 iPhone Home Screen icon/manifest integration remains intact.
- v0.61 front-of-screen incoming trade offer flow remains intact.
- v0.60 social-only media personality rule remains intact.
- v0.59 Games / Stats / News First hierarchy remains intact.
- v0.56 continuous real draft pipeline 2019–2026 remains intact.
- No simulation, CBA, trade evaluation, contract, draft, rating, schedule, injury or save logic changed.

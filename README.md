# NBA Courtside — v0.62 iPhone-First Visual System

**v0.62 supersedes v0.61 as the working development baseline.** This is a presentation/readability pass. It deliberately carries the large, photo-led, front-of-screen language introduced by the v0.61 incoming Trade Offer sheet across the wider game without changing simulation rules or save schema.

## Locked visual language

- **Important information is large.** Player names, salaries, OVR, scorelines, opponent/game information and required decisions no longer rely on 6–9px type on iPhone.
- **People are shown as people.** Roster, market, rotation, game-day and decision surfaces prioritize player photos beside the information that matters.
- **One readable row beats several tiny tiles.** Dense roster, contract, schedule, transaction and prospect layouts expand into larger scan-friendly rows on iPhone.
- **Front-of-screen sheets are the detail pattern.** Existing player, contract, prospect and transaction sheets now use the same rounded, elevated, high-contrast full-front visual language as the v0.61 Trade Offer sheet.
- **Primary actions are thumb-sized.** Key buttons and decision controls use larger touch targets; multi-choice decision areas stack vertically where a three-column layout would make text too small.
- **Summary first, depth second.** Dense two-column micro-grids collapse to one readable column on narrow phones. Advanced simulation information remains available but no longer dictates the first visual layer.

## Main franchise surfaces

### Home / required actions
- GM Action Center headings, descriptions and action rows are enlarged.
- Required decisions remain above normal franchise content.
- Incoming trade offers retain the dedicated v0.61 photo/pick/salary front sheet.

### Team
- Starting five becomes a horizontally scrollable photo rail instead of five tiny cards squeezed across an iPhone.
- Roster cards become large photo-led rows with readable name, role/position, age, OVR/status and salary.
- Rotation, depth and contract rows use larger player photos and readable metadata.
- Player profile sheets use the new full-front presentation while retaining ratings, morale, contract, health, history and development depth below the summary.

### League
- Schedule and standings rows are larger and easier to scan.
- Transaction/news rows use readable body text.
- Deep tables remain available but are no longer allowed to shrink key labels below practical iPhone reading size.

### Deals / Free Agency / Draft
- Player market cards, contract offers, prospect rows, draft order and draft trade calls are enlarged.
- Draft and contract detail sheets follow the same full-front visual pattern.
- Advanced CBA and scouting depth remains intact beneath the primary information.

### Game Day / Exhibition
- Live lineups become horizontally scrollable player-photo cards rather than five compressed columns.
- Rotation rows, play-by-play, controls, scoreboards and postgame leaders are enlarged.
- Box scores retain all columns but become horizontally scrollable when necessary instead of crushing player names and stat text.
- Exhibition team selection and primary actions receive the same touch/readability pass.

## Compatibility

- Save schema remains **25**.
- v0.61 incoming Trade Offer sheet and review flow remain intact.
- v0.60 social-only media-personality direction remains intact.
- v0.59 Games / Stats / News First Home hierarchy remains intact.
- v0.56 continuous real draft pipeline from 2019–2026 remains intact.
- No player ratings, contracts, CBA rules, simulation logic, draft logic or historical-universe data are changed by v0.62.
